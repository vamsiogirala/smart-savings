About Smart Savings

Smart Savings is a prototype personal finance dashboard built as part of my M.S. in Computer Science project under the supervision of Dr. Fuad Abu Zahra.

System Description

  • Reads financial transactions from CSV files and selected bank PDFs.
  • Stores data in a local SQLite database using SQLAlchemy.
  • Displays monthly spending trends and category breakdown charts.
  • Provides a simple AI-style forecast and savings tips.
  • Includes an Admin view with basic system statistics.

Technologies Used

  • Backend: Python, FastAPI
  • Database: SQLite (SQLAlchemy ORM)
  • Frontend: HTML, CSS, JavaScript, Chart.js
  • File Processing: pandas (CSV), pdfplumber (PDF)
  • Deployment (prototype): Gunicorn/Uvicorn on a free cloud service

Current Version

  • Version: 1.0 (Prototype)
  • Status: Single-user prototype, running locally and on a public demo URL.
  • Scope: Demonstrate end-to-end flow: upload → parse → store → visualize → basic prediction.

Planned Future Enhancements

  • User authentication (login, roles, multiple users).
  • Support for more bank PDF formats and better OCR-based parsing for scanned statements.
  • More advanced ML model for forecasting (e.g., time-series model).
  • Mobile-friendly responsive layout and PWA support.
  • Export reports as PDF or Excel.
