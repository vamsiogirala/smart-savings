How to Use Smart Savings

This page explains how a normal user should use the system step by step.

1. Home Dashboard

  • Balance – a fixed example balance (for demo).
  • Monthly Spend – total spending for the current month from your transactions.
  • Forecast (EOM) – an estimated end-of-month spending based on the last 12 months.
  • 12-Month Trend – line chart of monthly totals.
  • Category Breakdown – pie chart of spending by category (Dining, Groceries, etc.).
  • Recent Transactions – table with the most recent parsed transactions.

2. Uploading CSV Files

  1. Download a CSV export from your bank (most banks have an “Export” button).
  2. On the Home page, scroll to Upload Transactions.
  3. Under CSV Upload, click Choose CSV and select your file.
  4. The system will:
    • Read the date, description, and amount.
    • Try to detect the correct columns even if they are named “Posting Date” or “Transaction Date.”
    • Auto-categorize rows using simple rules (Dining, Groceries, Transport, etc.).
    • Insert transactions into the database and show a sample preview.
  5. After a short delay, the page reloads and your charts + table are refreshed.

3. Uploading Bank PDFs

  1. Scroll to Bank Statement (PDF) on the Home page.
  2. Click Choose PDF and select your bank statement.
  3. The system will:
    • Try to detect the bank type from the first page text (e.g., Bank of America).
    • For supported formats, extract rows with Date – Description – Amount.
    • Auto-categorize them and insert into the database.
  4. The result appears in Last Upload Result:
    • If "status": "ok" – parsing worked, and the sample rows are shown.
    • If you see "detail": "No valid transaction rows found..." – your PDF layout is not supported.

Important: Not all PDFs are text-based. Some banks provide scanned images or unusual layouts. In those cases, the safest option is to export a CSV file from online banking and use the CSV upload feature (which is more reliable).

4. Using the AI Prediction Button

  1. On the Home page, click the Predict (AI) button.
  2. The system calls the /api/predict endpoint, which:
    • Looks at the last 12 months of totals.
    • Computes an average and trend.
    • Returns a forecast value, confidence score, and 3 simple saving tips.
  3. The forecast number updates and the JSON response is shown in the small code box.

5. When Something Goes Wrong

  • Check the Last Upload Result area – most errors are explained as JSON.
  • If the dashboard doesn’t change, try refreshing the page.
  • If the server stopped, restart it with: 
    cd C:\Users\vam66\smart-savings
.venv\Scripts\activate
uvicorn app:app --reload
